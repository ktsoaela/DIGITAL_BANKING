## Status language

- **Implemented:** exists in the current repository and has been locally verified.
- **Foundation:** represented by a route, model, API contract, or starter UI but still needs production integration.
- **Planned:** required for a real financial product but not yet implemented.

The current application is a development/demo environment. It must not process real funds until the production controls in the TDD and engineering plan are complete.
